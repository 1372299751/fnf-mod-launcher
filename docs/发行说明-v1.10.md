# FNF 模组启动器 v1.10 · 中英双语

> 首发版本，同时带来界面多语言支持。

## 新增

- **界面语言：中文 / English** —— 设置窗口里切换，保存后启动器自动重启生效（配置项 `launcher.ini` 的 `lang=zh|en`，不写默认中文）
- **翻译引擎 `Lang`** —— 以中文原文为键，查不到时依次尝试 按行拆分 → 最长前缀 → 碎片替换 → 数字单位规则，四层兜底；没翻到的条目原样显示中文，不会出现空白或 `[MISSING]`
- **自绘消息框 `AskBox`** —— 替换系统 `MessageBox`，统一深色圆角卡片、主题色按钮，`是/否/取消` 跟随语言
- **右键菜单翻译** —— 曲目菜单（合听 / 伴奏 / 人声）与顶部「分类」菜单（全部分类 / 未分类 / 导出·导入清单）现在都会翻译
- **顶栏按钮自适应** —— 英文标签更长，按钮宽度按实测文字重算，不再被裁成 `ppearance`
- **i18n 工具链**（仓库内 `i18n/`、`tools/i18n.ps1`）—— 提取全部界面文案、生成 `LangData.cs`，改词条后一条命令重建

## 改进

- 标题栏、窗口标题、搜索框提示接入翻译
- 外观窗口「背景浓淡」滑杆文字接入翻译
- 资料窗、预览查看器、清理窗、启动日志窗、键盘统计窗全量英文化
- 关于窗、崩溃提示等多行长文本按行翻译，保留原始换行

## 修复

- 多行文本经过翻译层后换行丢失（GDI 不认孤立 `\n`，改为还原 `\r\n`）
- 自绘弹窗按钮四角出现暗色缺口（按钮底色改为窗口底色）
- 英文模式下窗口标题改变导致单实例检测失效（同时匹配中英标题）
- 早期机翻产生的 `z`、`E` 等垃圾译文（生成器已过滤单字母与残留中文的条目）

## 安装

1. 下载 `FNF-Launcher-v1.10.exe`，放到任意目录运行（单文件，免安装）
2. 首次启动选择「识别目录」—— 存放各个模组文件夹的那个目录
3. 之后把模组文件夹或 `.zip` / `.rar` / `.7z` 直接拖进窗口即可添加

需要 **.NET Framework 4.x**（Windows 10/11 自带）。解压 rar/7z 需本机装有 Bandizip / 7-Zip / WinRAR 之一；试听依赖 `libvlc.dll`，找不到时改用系统播放器。

## 已知问题

- 关于窗正文、部分崩溃分析长段落仍为中文（说明书性质，未逐句翻译）
- 拼接型文案依赖碎片替换，个别英文读起来偏生硬（例如 `modified 2026-11-07`）
- 界面文案目前只覆盖中文与英文，繁体/西语已从代码中移除

## 说明

- 翻译词条在 `i18n/core.tsv`，格式为 `中文 ⇥ English`，改完运行 `i18n/gen.ps1` 再 `build.ps1` 即可
- 本项目不包含任何游戏本体、模组或素材

## English

First public release, adding a bilingual (Chinese / English) UI.

- **UI language switch** in Settings (restart required). Stored as `lang=zh|en` in `launcher.ini`.
- **`Lang` translation layer** keyed by the original Chinese string, with four fallbacks: exact → line-by-line → longest-prefix → fragment substitution. Untranslated strings fall back to Chinese instead of showing blanks.
- **Custom `AskBox` dialogs** replacing the system message box: dark rounded card, accent-coloured buttons, localized labels.
- **Context menus localized**: song menu (Mix / Instrumental / Voices) and the Category menu.
- **Header buttons auto-size** to their text, so long English labels are no longer clipped.
- **i18n tooling** (`i18n/`, `tools/i18n.ps1`) to extract strings and regenerate `LangData.cs`.
- Fixes: lost line breaks in multi-line strings, dark notches at dialog corners, single-instance detection when the window title is translated, and leftover junk from an early machine-translation pass.

Single-file exe, no installer. Requires .NET Framework 4.x. rar/7z extraction needs Bandizip, 7-Zip or WinRAR; audio preview uses `libvlc.dll` when available.
