# FNF 模组启动器 · 对话总结（可直接粘贴到新对话）

## 一、项目现状

- 工程目录：`D:\fnf\launcher\`（源码 13 个 .cs + 资源）
- 产物：`D:\fnf\FNF启动器.exe`（单文件、免安装，793 KB 左右）
- GitHub 仓库：<https://github.com/1372299751/fnf-mod-launcher>（MIT 协议，发布目录 `D:\fnf\github\FNF-Mod-Launcher`）
- 技术栈：C# 5 / .NET Framework 4.x / WinForms，**界面几乎全部自绘**（无边框窗口 + 自定义控件）

### 构建命令（必须照抄）

```powershell
$csc='C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe'
$all=Get-ChildItem 'D:\fnf\launcher\*.cs' | Where-Object { $_.Name -ne 'MakeIcon.cs' }
& $csc /nologo /target:winexe /optimize+ /codepage:65001 /out:'D:\fnf\FNF启动器.exe' `
  /win32icon:'D:\fnf\launcher\launcher.ico' `
  /r:System.IO.Compression.FileSystem.dll /r:System.IO.Compression.dll $all.FullName
```

- **`/codepage:65001` 不能省**：源码是无 BOM 的 UTF-8，少了它中文全变乱码
- 编译前先 `Get-Process 'FNF启动器' | Stop-Process -Force`，否则报 CS0016（文件被占用）

## 二、功能清单（全部已实现）

**扫描识别**：识别目录一级子目录即模组；`FindExe` 优先同名 exe 并过滤 uninstall/crash 等；图标优先 `<mod>\icon.ico` → exe 图标 → 首字母兜底；引擎识别三重判断（结构特征 + exe 字符串签名 + 版本锚点）；后台补检测；`ModCache` 按签名缓存扫描结果。

**列表**：行入场动画、选中高亮块滑动、真滑块滚动、双击启动、右键菜单、Ctrl+Shift 多选（批量隐藏/分类/备份）、搜索（分词 + `分类:` `引擎:` `作者:` 前缀 + 首字母缩写）、排序（名称/最近/引擎）、分类筛选、隐藏、置顶。

**详情页**：图标 + 标题 + 引擎徽章；基本信息/运行统计两张卡；曲目面板（原版曲折叠、试听、播放进度 30fps、真滑块）；预览面板（截图缩略图，点第几张开第几张）；资料窗；切换模组三段错峰滑入动画；**紧凑模式**（详情区 <540px 时小图标 + 信息卡让位，并有「查看模组信息」小按钮）。

**启动**：启动前体检（非 ASCII 路径、缺 lime.ndll/assets/mods）、进程启动与记账、启动遮罩动画、托盘隐藏、启动日志（`启动日志.txt`）、退出码分析（0xC0000135 缺 DLL 等）、键盘统计（低级钩子只计数）、网页版条目。

**存档**：`backups\<模组>\<时间戳>\`，启动前自动备份（保留 5 份）、右键一键备份/恢复、`SavePaths` 探测 9 个常见存档位置。

**安装**：文件夹（复制/仅引用，拖拽支持）、压缩包（zip 内置解压，rar/7z 调本机 Bandizip/7-Zip/WinRAR），识别内层根目录、命名窗（含「以文件夹名 / 以 exe 名」两个按钮）、进度窗可取消并清理残留。

**下载中心**：分类卡片、站点图标（base64 内嵌，磁盘可覆盖）、交错入场动画。

**外观**：10 套预设强调色 + 自定义色相条、背景图 + 浓淡滑杆、界面缩放、窗口尺寸记忆。

**其它**：模组清单导出/导入（缺失清单写 `缺失模组.txt`）、GameBanana 查新入口、桌面/开始菜单快捷方式、Lua 脚本管理、清理窗（4 类垃圾）、诊断导出、关闭确认（隐藏托盘/直接退出/记住选择）。

## 三、多语言系统（最近重点）

- `Lang.cs`：以**中文原文为 key**，`Lang.T(s)` 四层兜底：**整串 → 按行拆分 → 最长前缀 → 碎片替换 → 数字单位规则**
- `LangData.cs`：由 `i18n/gen.ps1` 从 `i18n/core.tsv`（手工译文，280 条）生成，Key/En 一一对齐
- 接入点：`Ui.Text`（自绘文字）、启动时 `Lang.Sweep(this)`（控件树 + 菜单）、动态右键菜单 `Lang.SweepMenu(cm.Items,0)`、`AskBox` 自绘弹窗、标题栏、搜索框 `CueText`
- 切换：设置窗「界面语言」按钮 → 写 `launcher.ini` 的 `lang=` → **保存后自动重启生效**
- 只需中英两种（繁體/西语已从代码移除）
- 新增文案的翻译流程：加 `core.tsv` 一行（`中文⇥English`）→ 跑 `i18n/gen.ps1` → 编译

## 四、踩过的坑（务必记住）

1. **不要用"从第 X 行删到含某字符串的行"这种范围删除**——曾因此误删 `MainForm` 857 行。改代码一律用**精确字符串替换**，并让脚本打印"锚点命中/未命中"。
2. 字符串匹配是**精确匹配**：差一个空格、全角/半角、句号/逗号都不生效。要改先 `Select-String` 查出源码原文。
3. 拼接文案（`"共 " + n + " 个"`）无法整串匹配，必须靠前缀/碎片，或把代码改成片段翻译。
4. 多行文本翻译后要用 `\r\n` 还原换行，GDI 不认孤立 `\n`（否则整段糊成一行）。
5. 机翻接口（MyMemory）不可靠：`langpair` 的 `|` 不能被 URL 编码，且会把错误文本当译文缓存。**已废弃机翻**，全部手工词条。
6. 早期机翻垃圾（`z`、`E`）已由生成器过滤（单字母/残留中文的条目直接丢弃）。
7. `RoundButton` 第一次点击可能被窗口激活吞掉，需要响应的按钮用 `MouseUp`。
8. 自绘按钮四角暗块 = `BackColor` 与窗口底色不一致，设成 `Ui.Card` 即可。
9. 自绘控件若不经过 `Ui.Text`/`Label.Text`，翻译层抓不到（`FlatCheck`、`DownloadForm` 卡片都踩过）。
