## 2. 扫描与识别

### 2.1 自动发现模组（`Scanner.Scan`）
- 遍历「识别目录」的一级子目录 + 配置里 `ref.<路径>=1` 的额外目录（外部引用，`m.External = true`）。
- 每个候选目录走 `Scanner.Build(dir, cfg)`，失败（找不到 exe）返回 null 就跳过。
- 用 `HashSet<string> seen` 去重同目录。

### 2.2 exe 定位（`Scanner.FindExe`）
优先级：与文件夹同名的 exe（`Foo\Foo.exe`）→ 目录里第一个非黑名单 exe。
黑名单（`IsBad`）过滤：`uninstall`、`crash`、`updater`、`vc_redist`、`launcher`、`helper` 之类非游戏主程序。

### 2.3 图标（`Icons.Build`）
1. `<模组目录>\icon.ico` 存在则优先（`Icons.FromIco` 手工解析 ico 目录、挑最接近目标尺寸的帧）；
2. 否则 `Icon.ExtractAssociatedIcon(exe)`；
3. 都没有 → `Icons.Fallback` 画一个带首字母的圆角块。
- 结果按 (路径, 大小, 标签) 缓存在 `Icons` 里；`ModEntry.GetBig(px)` 在需要大图时按需放大重建。
- 网页版条目用 `Icons.Globe(px)`。

### 2.4 引擎 / 版本识别（`EngineDetector.Detect`）
三重手段叠加，命中越多置信度越高：
1. **结构特征**：`lime.ndll`、`mods\`、`assets\`、`pack.json`、`haxe` 相关 dll…
2. **exe 字符串签名**（`Signature` 表）：在 exe 里搜 `Psych Engine`、`NovaFlare`、`Kade`、`FPS Plus`、`Codename Engine` 等标记串。
3. **版本锚点**：`mods\pack.json` / `Project.xml` / `version.txt` 里的版本号。
- 结果写进 `ModEntry.EngineName/EngineVersion/EngineNote/EngineShort`，并缓存（见 2.7）。
- 后台补检测：启动后 `StartDetection()` 起线程 `DetectLoop()`，对"未识别/引擎未知"的模组逐个跑检测，完成后 `ApplyDetect` 回填并 `ModCache.Save`，列表逐行刷新。

### 2.5 元信息（`Scanner.FillMeta`）
一次性统计并挂到 `ModEntry`：曲目（`ScanSongs`）、预览图（`PreviewScan.Collect`）、文件数/总体积/最近修改（`EngineDetector.DirStats`）、周数/角色数/舞台数/视频数/音符总数/事件数（`JsonValue` 从 `pack.json`、`week*.json`、`scripts` 里抽字段）。

### 2.6 曲目扫描（`Scanner.ScanSongs`）
在 `<mod>\mods\songs`、`assets\songs`、`bin\mods\songs`、`bin\assets\songs` 四个位置找歌曲目录，每个目录读：
`Inst.ogg` / `Voices.ogg` 是否存在、时长（`OggMeta` 读 Vorbis 头，失败退回 libVLC）、BPM（`ReadBpm` 从 chart json / `meta.json` 里取）、难度数与音符数（`ReadChart`）。
`VanillaSongs.IsVanilla(名字)` 判断是否疑似原版曲（用于折叠）。

### 2.7 扫描缓存（`ModCache`）
- **签名**：`exe(修改时间+大小) ^ 模组目录时间 ^ songs 目录时间+子目录数 ^ Inst/Voices 时间` 做 XOR，得到 `long`。改文件/加歌都会让签名变。
- 配置键 `modcache.<模组名>` 存两段：签名 + 制表符分隔的完整元信息（引擎、行数、时长、歌曲清单、预览图路径…）。
- 命中就跳过昂贵的目录遍历与 json 解析；`ModCache.Hits` 记录命中次数，进诊断日志。

### 2.8 异步扫描（`MainForm.RescanAsync` / `Rescan` / `FinishScan`）
- **异步**（启动、`刷新` 按钮、F5）：把 `root` 和 `ref.*` 额外目录在 UI 线程取好，`cfg.SnapshotForRead()` 拍一份只读配置快照，起后台线程跑 `Scanner.Scan`；完成后 `BeginInvoke(FinishScan)` 在 UI 线程套用（网页版条目、配置回填、`ApplyFilter`、`LayoutSplit`、`StartDetection`）。
- 页脚提示：开始时「正在扫描模组…（root）」，结束「扫描完成：N 个模组（X ms）」。
- **同步**（重命名/安装/删除/分类之后等需要立刻拿到结果的场景）：同一套 `FinishScan`，只是直接在当前线程跑。
- `scanning` 标志防重入；`Config.SnapshotForRead()` 用 `lock (map)` 复制字典，避免后台线程与 UI 线程同时读写同一个 `Dictionary`。

## 3. 主界面骨架（`MainForm`）

- **无边框窗口**：`FormBorderStyle.None` + 自绘 `TitleBar`（44px 高）+ `ApplyFormRegion()` 给窗口设圆角 Region。
- **拖动/缩放**：标题栏处理拖动与双击最大化；`WM_NCHITTEST` 返回窗口边缘（`MRECT`/`MPoint` 两个 P/Invoke 结构）；`resizePoll`（20ms `Timer`）持续读鼠标与按下状态，实现无边框下的八向缩放（不依赖 `WM_SIZING`）；`WM_GETMINMAXINFO` 把最大化区域压回工作区，避免盖住任务栏。
- **布局**：`LayoutHeader / LayoutSplit / LayoutBottom` 三处算尺寸；左侧 `ModList`、右侧 `DetailPane`、顶部 `header`（搜索框 + 按钮）、底部 `footer`（提示行）。
- **动画循环**：所有 `IAnimatable` 控件（列表、详情、Toast、启动遮罩、标题栏渐变）统一由 `TickAnim` 定时调用 `Animate()`，谁还在动就 `Invalidate`。
- **单实例**：`Program.Main` 用命名 Mutex，第二个实例直接退出（退出码 0，不是崩溃）。
- **DPI**：`SetProcessDPIAware` + `Ui.Scale`（按 `Graphics.DpiX/96`）+ 用户缩放 `Ui.Zoom`，所有尺寸走 `Ui.S(v)`。

| 滚动 | `scroll/scrollTarget` 缓存目标值、每帧 0.34 缓动；滚轮 88px/格；右侧自绘滚动条可拖拽（`BarThumbRect`） |
| 双击启动 | `OnMouseDown` 里 420ms 内两次点击同一行 → `LaunchRequested` |
| 右键 | `ContextRequested` → `MainForm.ShowModMenu` |

### 4.1 排序（`ApplyFilter`）
三种：名称（默认，`OrdinalIgnoreCase`）、最近启动（`recent.*`）、引擎（`EngineName`）。置顶项永远排最前。

### 4.2 搜索（`MatchQuery`）
空格分词做 AND；支持前缀 `分类:xxx`、`引擎:xxx`、`作者:xxx`；`MatchesAcronym` 支持首字母缩写匹配（如 `sns` 命中 SNS Sadly Memories）。

### 4.3 分类筛选（`ShowCategoryMenu` / `ApplyFilter`）
菜单列出所有分类（含"未分类"），选中后 `catFilter` 生效；分类来自 `cat.<模组名>` 配置。

### 4.4 隐藏 / 置顶
- 隐藏：`hidden` 集合 + `hidden.<模组名>` 配置；隐藏的模组不参与列表与分类统计。
- 置顶：`pin.<模组名>`，排序时优先。

## 5. 右侧详情页（`DetailPane`）

### 5.1 布局（`LayoutAll`）
所有矩形（图标、标题、副标题、标签、两张信息卡、两个折叠头、曲目区、预览区、按钮、紧凑模式的"查看模组信息"按钮）**都在这一个方法里算好并存字段**，绘制和命中测试都只读这些字段。

两种版式：
| 条件 | 版式 |
|---|---|
| 详情区高度 < 540px | **紧凑**：图标 72 内联标题、副标题一行、信息卡放到折叠头下方空白处、按钮贴底 |
| 否则 | **标准**：图标 120、标题/副标题/标签纵向排列、两张信息卡（基本信息 + 运行统计）在标题下方 |

### 5.2 信息卡（`DrawInfoCard`）
签名改成**按矩形绘制**：`SetClip(矩形)` + 按 `(高度-34)/26` 算能放几行、只画这么多行。这是"文字跑到框外/压到按钮"问题的根治点。

### 5.3 曲目面板
- `BuildSongRows()`：把曲目整理成行；`mod.VanillaOpen=false` 时把疑似原版曲折叠成一行「▾ 疑似原版曲目（N 首）」。
- 绘制 `DrawSongs`：`SetClip(songsRect)`，行高 30px，播放中的行高亮并显示实时进度条；右侧**真滑块**（轨道 White 22 + 滑块 White 90，高度按可见/总高、位置按 `songsScroll/maxScroll`）。
- 滚动：`songsScroll/songsScrollTarget` 每帧 0.34 缓动，滚轮 88px/格。
- 交互：`HitSong`（按 `(p.Y - songsRect.Y + songsScroll)/30` 反算行号）→ 点击播放、右键 `ShowSongMenu`（合听 / 伴奏 / 人声，`OpenSongTrack`）、点折叠头行切换 `VanillaOpen`。

### 5.4 预览面板（`DrawPreviews`）
`PreviewScan.Collect` 得到的 `List<PreviewImage>` 按固定 tile 尺寸铺开（每行算列数，超出显示 `+N`），`HitPreview` 反算下标，点击 → `PreviewOpenRequested` → `MainForm.OpenPreview` → `PreviewViewer(imgs, index)`（**按点击的那一张打开**）。

### 5.5 资料窗口
`InfoBtnRect()`（或紧凑模式的「查看模组信息」小胶囊 `infoChipRect`）→ `InfoWindowRequested` → `MainForm` 里 `new InfoForm(detail.Mod).ShowDialog(this)`。两种版式都是**弹窗**。

### 5.6 切换模组的过渡动画
`changeAt` 打时间戳，绘制时按三段错峰位移：
- 图标/标题：`EaseOutBack(Progress(changeAt, 330ms))` 回弹放大
- 信息卡：`SlideIn(changeAt+60, 300)` 从下方 14px 缓出
- 折叠头：`+110ms`；曲目/预览内容 + 按钮：`+160ms`
动画窗口 520ms，期间 `Animate()` 持续请求重绘；位移只在绘制时临时叠加，画完立即还原，命中测试仍用原始矩形。

## 9. 启动游戏

### 9.1 启动流程（`MainForm.Launch`）
1. 网页版 → `LaunchWeb`（`Ui.ShellOpen` 打开 URL）。
2. 已在运行 → `BringToFront`（`ShowWindow` + `SetForegroundWindow`）而不是再启一个。
3. exe 不存在 → 标记 `ExeMissing`、弹提示、刷新列表。
4. **启动前体检**（只警告不阻止）：路径含非 ASCII、目录缺 `lime.ndll`/`assets`/`mods` → 弹确认框。
5. `Process.Start(ProcessStartInfo{ FileName=exe, WorkingDirectory=LaunchDir, Arguments=Args, UseShellExecute=true })`。
6. 记账：`recent.*`、`count.*`、`last`，`cfg.Save()`。
7. `LaunchLog.Begin(...)` 写"启动中"记录 → `WatchExit` 后台线程等进程退出。
8. `SaveBackup.Backup(m, 5)`：**每次启动前自动备份存档**。
9. `KeyStats.CurrentMod = m.Name`：之后的按键统计算到这个模组名下。
10. `overlay.Play(m, ...)` 播放"正在启动"遮罩动画，动画结束后若 `minimize=1` 则 `HideToTray()`。

### 9.2 退出监看（`WatchExit`）
后台线程 `p.WaitForExit()`（带超时轮询），拿到退出码与耗时 → `LaunchLog.End(rec, code, ms, note)` → `Analyse` 给出可能原因；异常退出时弹 `CrashForm`（或页脚提示）。

### 9.3 运行状态（`UpdateRunningState` / `MarkRunning`）
`runningGames`/`launchedExes` 记录启动过的进程；定时器检查进程是否退出，刷新列表里的"运行中"标记；用户从托盘恢复时若游戏已退出则恢复主窗。

### 9.4 启动遮罩（`LaunchOverlay`）
覆盖在详情区上的自绘层：模糊背景 + 模组图标 + "正在启动"文字 + 进度条动画，`Play(mod, done)` 播完回调。

### 9.5 网页版条目
配置 `web.<名字>=<url>`，`Rescan` 时合成 `ModEntry{IsWeb=true}`，缩略图用 `Icons.Globe`，右键可复制网址，图标可自定义（`wicon.<名字>`）。

## 10. 启动日志与崩溃分析（`LaunchLog.cs`）

- `LaunchRecord`：模组、引擎、exe、参数、开始时间、退出码、耗时、备注。
- 持久化到 `启动日志.txt`，格式一行一条；`Begin` 先写 `pending` 记录，`End` 再补全，进程意外终止时下次启动能看出"上次没正常退出"。
- `Analyse`（分析规则）：
  - 退出码 `0xC0000135` → 缺 DLL / 没装 VC++ 运行库；
  - `0xC0000005` → 访问冲突（常见于 mod 与引擎版本不匹配）；
  - `0xC0000142` → DLL 初始化失败；
  - 运行时间 < 3 秒 → 多半是启动即崩，提示看引擎日志；
  - 结合引擎类型给出对应建议（Psych/NF 各自的常见坑）。
- `LaunchLogForm`：历史列表 + 详情 + 一键打开日志文件；`CrashForm`：异常时弹出的分析窗口。

## 11. 存档备份（`Backup.cs`）

| 点 | 实现 |
|---|---|
| 根目录 | `SaveBackup.Root` = **exe 同级 `backups\`**（不再放 `launcher\backups`）；`EnsureMigrated()` 首次访问时把旧目录整体搬过来（只搬一次） |

## 12. 添加 / 安装模组

### 12.1 文件夹
- **添加模组**窗口（`AddForm`）：选目录 → 返回 `FolderPath`；`MainForm` 再问「复制到识别目录」还是「只添加引用」（`MessageBox YesNoCancel`）。
- 复制：`CopyDir` 递归拷贝到 `root\<目录名>`；已存在则拒绝。
- 引用：写 `ref.<路径>=1`，扫描时作为 `External` 条目。
- **拖拽**：`DragDropHandler` 支持文件夹与 `.zip/.rar/.7z`；文件夹若已在 root 下 → 直接选中并提示；否则走上面的询问流程。

### 12.2 压缩包（`ZipInstall`）
1. `Detect(zip)`：读压缩包条目，找**最浅一层**含 exe 的目录作为安装根；没有 exe 就退回 `lime.ndll` / `mods\pack.json` / `modsList.txt` 判定；返回 `innerRoot / exeName / fileCount`。
2. `ZipInstallForm`：显示"识别到压缩包内容"（文件、内部根目录、游戏 exe、文件数、安装到），下面给模组起名（同时作为文件夹名），并提供**两个小按钮**：
   - 「以文件夹名称命名」→ 填内层文件夹名（没有就用压缩包名）
   - 「以 exe 文件命名」→ 填 exe 名（去掉扩展名）；压缩包里没 exe 会提示
3. `Install(zip, innerRoot, targetDir, out err, cancel)`：
   - `.zip` 用内置 `System.IO.Compression` 解压；
   - `.rar/.7z` 用 `FindExtractor()` 找到的本机 Bandizip / 7-Zip / WinRAR 命令行解压（`RunExtract`）；
   - 边解压边 `CopyTree` 到目标目录，`cancel` 回调可中断。
4. `InstallWithProgress`：`ProgressForm` 显示"已拷贝 / 总数"进度，可点「取消安装」中断；失败或取消时清理 `targetWasNew` 的残留目录。

### 12.3 安装后
`Rescan()`（同步）→ `SelectByName(名字)` 自动选中新模组；若目标已存在会先问是否合并覆盖。

## 19. 已知限制（明确说明，不夸大）

1. **详情区不能整体滚动**：窗口高度 < 540px 会自动切紧凑版式（信息卡挪到折叠头下方、有面板展开时让位），但没有"整页滚动"；这是之前几轮没能做干净的部分，目前用版式切换规避。
2. **更新检测是手动的**：只显示本地版本并打开 GameBanana 搜索页，不解析线上版本号。
3. **rar/7z 依赖本机解压工具**：没有 Bandizip/7-Zip/WinRAR 时会提示不支持；zip 是内置解压。
4. **试听/混音依赖 libVLC**：找不到 `libvlc.dll` 时退化为"用系统播放器打开音频文件"。
5. **键盘统计是全局低级钩子**：部分安全软件会提示；只计数不记录输入内容。
6. **单实例**：重复启动第二个进程会静默退出（退出码 0），不是崩溃。
7. `MakeIcon.cs` 是生成图标的工具，编译时被排除，不属于运行时逻辑。
