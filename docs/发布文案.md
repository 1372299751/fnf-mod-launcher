# 发布时可以直接抄的文案

建仓库 / 发 Release 时，页面会问「描述、标签、发布说明」。下面这些中英对照，复制粘贴就行。

---

## 1. 仓库创建页

**Repository name**

```
fnf-mod-launcher
```

**Description**（英文一行，GitHub 的搜索主要吃这段）

```
A Windows launcher for Friday Night Funkin' mods: auto-scan, engine detection, song preview, save backup, archive install.
```

**勾选框**：README / .gitignore / license **全都不勾**（仓库里已经有了）。

## 3. Release 页面

**Tag**

```
v1.9
```

**Release title**

```
FNF 模组启动器 v1.9 · FNF Mod Launcher v1.9
```

**Describe this release**

```markdown
首个公开版本。

### 功能
- 自动扫描模组文件夹，识别引擎与版本（Psych / NovaFlare / Kade / FPS Plus …）
- 曲目试听（合听 / 伴奏 / 人声）、截图预览、资料窗口
- 启动前体检 + 启动日志 + 异常退出分析
- 存档自动备份与一键恢复
- 拖入文件夹 / .zip / .rar / .7z 即可安装，带进度与取消
- 分类、隐藏、置顶、重命名、多选批量操作
- 10 套配色 + 自定义色相、背景图与浓淡、界面缩放

### 说明
- Windows 10/11，单文件 exe，免安装
- 界面为中文；需要 .NET Framework 4.x（系统自带）
- 解压 rar/7z 需要本机装有 Bandizip / 7-Zip / WinRAR 之一
- 试听功能依赖 libvlc.dll（找不到时会改用系统播放器打开音频）

---

### English
First public release. A Windows launcher for Friday Night Funkin' mods: auto-scan with engine detection, song preview, screenshot gallery, save backup, and drag-and-drop install for folders and zip/rar/7z archives.
Single-file exe, no installer. UI is Chinese only. Requires .NET Framework 4.x (built into Windows). rar/7z extraction needs Bandizip, 7-Zip or WinRAR installed; audio preview uses libvlc.dll when available.
```

**Attach binaries**

把 `D:\fnf\github\FNF-Mod-Launcher\dist\FNF启动器.exe` 拖进附件框。

## 4. 关于"要不要加洋文"的结论

| 做法 | 建议 | 原因 |
|---|---|---|
| README 加一段**简短英文摘要** | ✅ 已经加好了 | 老外搜到能一眼看懂这是干什么的，也说明清楚"界面只有中文"，不会下载后骂人 |
| 仓库描述 / Topics 用英文 | ✅ 建议 | GitHub 的搜索和推荐主要靠这些，中文标签权重低 |
| Release 说明中英各一段 | ✅ 建议（上面已备好） | 下载页是最常被看到的地方 |
| 完整双语 README（`README.en.md`） | ⏳ 以后再说 | 每改一次功能要同步两份，新手容易只改一边导致内容打架 |
| 把界面本身翻译成英文 | ❌ 暂不建议 | 全部文案散在 11 个文件里（含大量自绘布局），工作量大且容易撑破排版；等真有海外用户提需求再做 |

**一句话**：文档留一段英文摘要就够，界面先保持中文。
